📐 Chapter 1

संबंध एवं फलन

📖 Notes – Part 1

1. संबंध (Relation)

यदि A और B दो समुच्चय हैं, तो A×B के किसी उपसमुच्चय को A से B में संबंध कहते हैं।

A×B को Cartesian Product कहते हैं। यदि A में m अवयव और B में n अवयव हैं, तो A×B में mn ordered pairs होंगे।

2. क्रमित युग्म

(a,b) एक ordered pair है जिसमें पहला अवयव a और दूसरा अवयव b होता है।

दो ordered pairs (a,b) और (c,d) बराबर होंगे यदि a=c तथा b=d।

3. Cartesian Product

A×B = {(a,b) : a∈A और b∈B}

उदाहरण: यदि A={1,2} तथा B={3,4}, तो

A×B={(1,3),(1,4),(2,3),(2,4)}

4. संबंध के प्रकार

किसी समुच्चय A में संबंध R को विभिन्न प्रकारों में बाँटा जा सकता है।

Reflexive: हर a∈A के लिए (a,a)∈R होना चाहिए।

Symmetric: यदि (a,b)∈R है तो (b,a)∈R होना चाहिए।

Transitive: यदि (a,b)∈R और (b,c)∈R है तो (a,c)∈R होना चाहिए।

5. फलन (Function)

A से B में संबंध f को function कहते हैं यदि A के प्रत्येक element का B में केवल एक image हो।

इसे f:A→B लिखते हैं।

6. Domain, Codomain और Range

Domain: वे सभी input जिन पर function defined है।

Codomain: जिस set में outputs लिए जाते हैं।

Range: वास्तव में प्राप्त होने वाले outputs का set।

📖 Notes – Part 2

7. One-One Function

यदि अलग-अलग inputs के images भी अलग-अलग हों, तो function one-one कहलाता है।

यदि f(a)=f(b) से a=b प्राप्त हो, तो function one-one है।

8. Many-One Function

यदि दो या अधिक अलग-अलग inputs का image समान हो सकता है, तो function many-one कहलाता है।

9. Onto Function

यदि codomain का प्रत्येक element किसी न किसी domain element की image हो, तो function onto कहलाता है।

10. Into Function

यदि codomain के कुछ elements किसी भी input की image नहीं हैं, तो function into कहलाता है।

11. Into और Onto में अंतर

Onto function में पूरा codomain cover होता है, जबकि into function में codomain का कुछ भाग unused रह सकता है।

12. Identity Function

यदि f:A→A तथा प्रत्येक a∈A के लिए f(a)=a हो, तो इसे identity function कहते हैं।

13. Composite Function

यदि f:A→B और g:B→C हैं, तो g∘f एक composite function है।

(g∘f)(x)=g(f(x))

14. Invertible Function

किसी function का inverse तभी function के रूप में प्राप्त किया जा सकता है जब उपयुक्त रूप से function one-one और onto हो।

15. महत्वपूर्ण बात

हर function एक relation है, लेकिन हर relation function नहीं होता।

⭐ Important Questions

Q1. संबंध की परिभाषा लिखिए।
Ans. A×B के किसी उपसमुच्चय को A से B में संबंध कहते हैं।
Q2. फलन किसे कहते हैं?
Ans. A से B में ऐसा संबंध जिसमें A के प्रत्येक element की B में केवल एक image हो, फलन कहलाता है।
Q3. Domain क्या है?
Ans. Function के सभी possible input values का set domain कहलाता है।
Q4. Range क्या है?
Ans. Function से वास्तव में प्राप्त output values का set range कहलाता है।
Q5. One-one function क्या है?
Ans. जिसमें अलग-अलग inputs के images अलग-अलग हों, वह one-one function है।
Q6. Onto function क्या है?
Ans. जिसमें codomain का प्रत्येक element किसी input की image हो, वह onto function है।
Q7. Identity function क्या है?
Ans. f(x)=x वाला function identity function कहलाता है।
Q8. Composite function का formula लिखिए।
Ans. (g∘f)(x)=g(f(x))
Q9. Reflexive relation की condition लिखिए।
Ans. प्रत्येक a∈A के लिए (a,a)∈R होना चाहिए।
Q10. Symmetric relation की condition लिखिए।
Ans. यदि (a,b)∈R है तो (b,a)∈R होना चाहिए।
Q11. Transitive relation की condition लिखिए।
Ans. यदि (a,b)∈R और (b,c)∈R हो तो (a,c)∈R होना चाहिए।
Q12. Relation और function में अंतर लिखिए।
Ans. प्रत्येक function एक relation होता है, लेकिन प्रत्येक relation function नहीं होता।
