📖 1. Important Notes

Relation

यदि A और B दो समुच्चय हैं, तो A × B का कोई भी उपसमुच्चय A से B में Relation कहलाता है।

Function

एक Relation f : A → B एक Function कहलाता है यदि A के प्रत्येक अवयव की B में केवल एक image हो।

Domain

Function में प्रयुक्त सभी input values का समुच्चय Domain कहलाता है।

Range

Function से प्राप्त सभी output values का समुच्चय Range कहलाता है।

Codomain

B का पूरा समुच्चय Codomain कहलाता है।

⭐ 2. Important Concepts

  • One-One Function
  • Many-One Function
  • Onto Function
  • Into Function
  • Bijective Function
  • Identity Function
  • Composite Function
  • Inverse Function

One-One Function

यदि अलग-अलग inputs की images भी अलग-अलग हों, तो function One-One कहलाता है।

Onto Function

यदि Range = Codomain हो, तो function Onto कहलाता है।

Bijective Function

जो function One-One और Onto दोनों हो, वह Bijective Function कहलाता है।

📌 3. Important Formulas

(f ∘ g)(x) = f(g(x))

(g ∘ f)(x) = g(f(x))

यदि f एक invertible function है, तो उसका inverse f⁻¹ होता है।

f⁻¹(f(x)) = x

🔄 8. Quick Revision

  • Relation → A × B का उपसमुच्चय
  • Function → हर input की केवल एक image
  • One-One → अलग input → अलग output
  • Onto → Range = Codomain
  • Bijective → One-One + Onto
  • Composite → f(g(x))
  • Inverse → f⁻¹
